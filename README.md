# Mine Games

Jogos que eu crio para passar o tempo.

## Sobre

Repositório com jogos e experimentos feitos por diversão, usando principalmente Python.

## Estrutura

### 🎮 jogos-ctrl
- `jogo_sao_patricio.py` → Jogo temático de São Patrício
- `jogo_simplificado` → Versão simplificada de jogo

### 🕹️ meus-jogos
- Experimentos e testes de jogos
- Arquivos de configuração e imagens

### 🗡️ rpg
- `Escdo_app` → Projeto de RPG
- `começando_rpg` → Primeiros passos / protótipo de RPG
